# optional_data/ — внешний контент проекта (полка, не учебный корпус)

| папка | что | статус |
|---|---|---|
| `raw/` | сырые необработанные данные из интернета (скрейп OSS scad, CADPrompt, манифест и лицензии) | СЫРЬЁ: не валидировано, в обучение не идёт без репака+`omni validate` |
| `data/` | исходники поставок №1–7 (para1, parts, gen2/3, scale1, sketchN…) | ДОКАЗАТЕЛЬНАЯ база корпуса v9; не удалять до приёмки v14 (E6-b чинит промпты отсюда) |
| `gen2/` | поставка gen2 как получена | то же |
| `specs_probe/`, `specs_probe_v2/` | прогоны пробника [SPECS] (до/после фикса минера) | evidence, не трогать |
| `zero_to_cad_1m/` | (на машине владельца) parquet-сплиты Zero-to-CAD 1M, ~3.4 ГБ | вне git (.gitignore); сырьё для voxel-GT банка холста, НЕ для LM-обучения как есть |

Обучающий контур живёт в `data/processed/*` (вне git): combined/splits — только после
OpenSCAD-валидатора (accepted-only, AGENTS.md).
