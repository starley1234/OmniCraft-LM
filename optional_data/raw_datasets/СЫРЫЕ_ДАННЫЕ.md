# ⚠ СЫРЫЕ ДАННЫЕ — не для обучения «как есть»

Каталог `optional_data/raw_datasets/` содержит внешние датасеты, скачанные
из интернета 2026-10-04 (агент без GPU, сеть: github.com доступны,
huggingface.co/hf-mirror — блокировались). Статус всех файлов — **сырьё**:

1. НЕ прогнаны через `omni validate` (OpenSCAD/manifold) — компилируемость
   неизвестна;
2. НЕ разложены в схему `src/data/schema.py` (нет `verification.target_bbox`,
   вердиктов, `code_sha256`);
3. НЕ прошли фильтр `$fn = 32;` и политику accepted-only;
4. Лицензии смешанные (MIT/BSD/GPL/NOASSERTION в `index.csv`) — перед
   обучением на публикации сверять; для приватного обучения допустимо
   исследование.

Порядок обработки: репак в JSONL → `tools/validate_dataset.py --backend
openscad` → `omni split` → только затем в учебный корпус (`AGENTS.md`,
железный закон про `.accepted.jsonl`). Подробные карточки — в `MANIFEST.md`.
