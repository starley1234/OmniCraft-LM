## Очередь задач, которые я (агент без GPU) готов взять сразу
1. **E3-патч как код-ревью-подсказка** (внедряет владелец): augmentation в
   `trainer.build_sequence` — ~60% блок истинный, ~30% `extract_specs_from_text(тот же
   промпт)` (self-consistent серый блок), ~10% деградированный (class=слой, bbox=100³) при
   неизменном коде. ⚠ Критично: `_sample_lengths` обязан прогнать то же преобразование
   (иначе обрезы пойдут), сид — sha1(id+':specsnoise') без зависимости от шага. Флаги
   `--specs-noise/--specs-degrade` (default 0 = поведение побайтово прежнее + golden-тест на это).
2. **Датасеты/генераторы:**
   - пересобрать para1 с guard'ом «размеры в перефразе = target_bbox» (сверка тем же
     `_mine_bbox`, 15%): снимает системный риск перефразировок, пропущенный фильтром v8
     (тот видел только `AxBxC` без пробелов);
   - repair-прачечная `parts_import` (airducts, handles, leverarms, bearings, flanges,
     voidplates): промпт-фичи не в коде — либо переписать промпты от фактической геометрии,
     либо выбросить семейства; могу составить ТЗ генераторов-исправлений и приёмочные
     проверки «существительное фичи → токен в коде»;
   - новые wire-генераторы (задача A из `NEXT_SESSION_V9`): 12/42 два прогона подряд —
     скучены не перефразировками; могу спроектировать 6 семейств (фермы Пратта/Варрена с
     раскосами-ушами, эстакада, вантовый мост, башня крана с поворотной рамой, ферменное
     крыло, консольный козёл) в формате `tools/dataset_*` с seeded-генерацией и
     приняточным контуром (watertight/15%/скелет-диверсификация);
   - conv-аугментация «примерно ØN»: научить модель жить с дефолтным блоком при
     безразмерном тексте (пары «текст без размеров + block=default + код с GT-масштабом»
     сейчас в обучении отсутствуют — отсюда 2/6 conv).
3. **Минер-бэклог (доля ≥135/140):** oval «centres C + pad W → A=C+2W»; составные высоты
   (flange+neck, base+стопорные стойки: z=толщина+высота надстройки); выводные Ø
   (шкив: делительный+2·модуль; косозуб — допуск). Каждый — с корпусной статистикой
   и тестом; без эвристик, не подтверждённых манифестом.
4. **QA/тесты:** golden-снапшоты `[SPECS]` для фиксированных промптов (защита от
   молчаливой смены блока при рефакторингах); тест «число `[/SPECS]` в ответе API == 1»;
   e2e-мок: probe CASES → блок не обязан быть верным, но **не должен противоречить**
   (topology==_default_topology(canvas), class∈словарь) — как инвариант на все времена.
5. **Второй проход визуала:** `render_family_previews.py --per-family 3` на 6 repair-семейств
   и на всех para1-кандидатах из `runs/reaudit_specs/candidates.csv` — сверю картинку с
   промптом и пришлю diff-вердикты (формат `filter_corpus_by_verdict.py` уже принимает).
   Для «расширения вердиктов на всё семейство» (в шаблоне по 1 id на семью):
   `jq -r 'select(.metadata.origin==FAMILY)|.id'` по корпусу → плодятся в csv.
