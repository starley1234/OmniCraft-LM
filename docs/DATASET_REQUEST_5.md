# Заявка №5: домашка по остальным холстам (для внешнего агента)

> Статус: gen2/gen3/place1/para1/sketch1 прошли приёмку нашим настоящим
> OpenSCAD CLI (`--backend=manifold`): 100% каждый пакет. Инварианты из
> `DATASET_REQUEST.md` в силе: `$fn = 32;`, положительные перекрытия,
> самодостаточность, ≤ 12 КБ, размеры 5–250 мм. Дополнительно действует
> закон place1: **каждое число промпта живёт в коде** (аудитор
> консистентности прогоняйте; порог ≥ 97%).

Холсты — это специализированные «блокноты» модели; данные под них разные по
форме ground truth (GT). Ниже каждый блок самодостаточен.

---

## Блок W2. Каркасный холст (wire) — второй заход | `optional_data/data/wire2/`

Модель этого холста учится предсказывать **3D-граф**: узлы (мм) и рёбра
(индексы). Код — стержни `cylinder`/`hull` между узлами.

**Что делать:** 1 200–1 600 сцен по укрупнённым каркасам:
- пространственные башни с переменным сечением по ярусам (сужение к верху);
- мостовые фермы разных типов в одной сцене (боковые + нижняя проезжая часть);
- решётчатые опоры по типам: X-раскосы, K-раскосы, Праtt/Уоррен, портальные;
- трубные трассы с отводами 45°/90° и коллекторами (hull-цепочки);
- косые призмы/антенные мачты с оттяжками (ряд прижимных узлов на земле);
- силовые клетки (roll cage) 3×2 секции, главный и вспомогательный обручи.

**Манифест:** прежний + обязательный `graph { "nodes": [[x,y,z]...мм],
"edges": [[i,j]...], "member_radius_mm": r }`. Рёбра только между реальными
узлами; длина ребра > 2r; граф связный; изолированных узлов нет. Узлов 6–64 на
сцену. Толщины рёбер 1.5–5 мм.

**Проверяйте сами:** связность BFS от узла 0; длины > 0; bbox == манифест; ни
одного ребра, не совпадающего с кодом; числа промпта ⊆ кода.

## Блок S2. Эскизный холст (sketch) — второй заход | `optional_data/data/sketch2/`

Холст учит **замкнутый 2D-контур** (точки полигона) и способ его вытяжки.
Существующий sketch1 — идеальный образец формата (cargo его на вашей ветке).

**Что делать (усложнение sketch1):** 1 200–1 800 деталей:
- профили с ПОЛОСТЯМИ: контур + окна/карманы (первый `polygon` — тело,
  вычитайте вторым `polygon` после экструзии — это легально);
- составные профили с дугами (дуги аппроксимируйте точками с ≤ 1° шага);
- ступенчатые планки разной толщины (linear_extrude двух совмещённых);
- тела вращения с канавками/буртиком/резьбовой проточкой (rotate_extrude),
  профиль допускает диаметральные выточки;
- зубчатые сектора (мириады на дуге), направляющие V-образные.

**Манифест:** прежний sketch1-формат + `profile` (точки CCW, мм, 6–64) и
`extrude {"kind": "linear", "height_mm"} | {"kind": "rotate"}`; детали с
полостями добавляют `voids_profiles: [ [точки], ... ]` и
`void_depth_mm`/полную глубину. Профили простые (без самопересечений) — наша
сторона проверит сложение Shoelace и скомпилирует manifold'ом.

## Блок A2. Сборочный холст (assembly) — второй заход | `optional_data/data/asm2/`

Холст учит дерево преобразований SE(3) деталей сцены: у каждой детали модуль,
в сцене явные `translate/rotate`. Существующий asm1 (900 сцен) — образец.

**Что делать:** 800–1 200 сцен — более живые компоновки:
- станции «вал + 2 подшипника + стакан + крышка» под разные посадки;
- «мотор NEMA + кронштейн + шкив + ремень» (ремень — гибкая лента polyhedron);
- «фланец + прокладка + крышка + N болтов по окружности»;
- «рамка + 4 стойки + верхняя рама»; «тележка: ось + 2 колеса + вилка»;
- петли: плоскость+створка, сцепленные, под углом 0/45/90°.

**Дисциплина как в asm1:** углы только кратные 45°; pазовый зазор ≥ 0.2 мм;
каждый модуль без аргументов; у каждой детали свой цвет
(`color([r,g,b])` — нам это не мешает; цвет не вычисляем).
Манифест прежний: `assembly: [{"module": str, "t": [x,y,z] мм,
"q": [x,y,z,w] кватернион}...]`; целостный код ≤ 12 КБ на сцену.

## Поставка и приёмка

Одним коммитом на ветку: три каталога с манифестами, `SHA256SUMS.txt`,
`GENERATION_REPORT.md` (включая: числа аудитора консистентности по блокам,
0 несвязных графов, 0 простых/самопересекаемых профилей, число сцен с
нарушением зазора). Мы: настоящий CLI по каждому блоку + сборочный аудит
(компоненты = частям, all watertight) + полевая выборка рендеров.
