# Демонстрация: как устроена и как обучена OmniCraft-LM (Фаза 1)

## Живая демонстрация (обученная модель, свежие промпты — не из трейна)

Промпт → модель генерирует код OpenSCAD → настоящий компилятор `--backend=manifold`
проверяет меш → рендер.

| Промпт (RU) | Результат |
|---|---|
| Ферма 180×30×30 с диагональными связями | ✅ ферма с раскосами, bbox **180×30×30 (ошибка 0.03%)**, watertight — `data/demo/demo_truss.png` |
| Фланец 60×60×10, центральное ø20, 4 отв. М5 | ✅ компилируется, bbox точно 60×60×10, центральная расточка есть; угловые отверстия поставлены схематично — `data/demo/demo_flange.png` |
| Пластина 80×50×6, 4 отв. ø6 по углам | ✅ конверт точный 80×50×6, часть отверстий попала на оси вместо углов — `data/demo/demo_plate.png` |
| Втулка 30×ø15/ø8 | ❌ модель ушла в повторение переменных (дегенерация длинного хвоста) |

Контроль (та же машина с нулевой точки, до обучения): 0/42 — чистый бэкбон CAD не пишет.
Честное чтение: **формат, словарь конструкций и габариты — выучены причинно;
точная постановка признаков и стойкость на длинных/редких формулировках —
следующий фронт (данные, gen2/gen3 уже влиты).**

## Как обучена

- **Изоляция слоёв (Multi-LoRA):** у каждого холста свой путь и свой адаптер
  (`lora_voxel`, `lora_wire`, … r=16, alpha=32, dropout 0.05). Остальные
  заморожены. Нет катастрофического забывания.
- **Один проход:** префилл-хук на слое 12 сам считает вектор холста
  (In→Canvas→Out) и вставляет его резидуально — градиент L_LM доходит до
  холста без второго прогона.
- **Суммарный лосс:** L = L_LM + 0.1·L_aux; у wire L_aux = Chamfer(узлы) +
  BCE(рёбра) против ГТ-графа (упал 1.11 → 0.15 — канвас реально учит геометрию).
- **Доверие к данным:** каждая запись скомпилирована настоящим OpenSCAD
  (watertight, 1 компонента, bbox ≤15%), хэш-код зафиксирован.
- **Воспроизводимость/откат:** нулевая точка с SHA-256; откат бит-экзактен,
  доказан экспериментально.
- **Железо:** RTX 5060 Ti; обучение в WSL2 (запуск ядер Linux ~5 мкс против
  ~32 мкс на WDDM — ×5.8 темпа); потолок 14 GiB VRAM жёсткий
  (`set_per_process_memory_fraction`), батчи по токен-бюджету.
