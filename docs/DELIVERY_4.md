## A. Закон раскладки — то, ради чего эта заявка

**Формулировка.** Каждое размерное число из промпта обязано присутствовать в
коде (значением переменной или координатой), а каждая координата отверстия в
коде — вычисляться из переменных заголовка, а не быть литералом.

**Как это выглядит в файле** (`optional_data/data/place1/cornerplates/part_0001.scad`,
промпт: «профильную пластину габаритом 70 x 60 x 6 мм. По углам 4 отверстия
ø10.5, 8 мм от кромки, отверстия сквозные»):

```openscad
$fn = 32;

// --- parameters (mm) ---
plate = [70, 60, 6];  // overall size (x, y, z)
seat_tol = 0.05;      // tolerance at the seating features
free_tol = 0.3;       // general tolerance on the free sizes
holes = 4;            // number of holes the drawing asks for
hole_d = 10.5;        // hole diameter
edge = 8;             // hole centre offset from the plate edge

// --- derived feature positions (mm) ---
corner_x = plate[0] / 2 - edge;  // = 27   corner hole X
corner_y = plate[1] / 2 - edge;  // = 22   corner hole Y
feature_centers = [
  [corner_x, corner_y],
  [-corner_x, corner_y],
  [-corner_x, -corner_y],
  [corner_x, -corner_y]
];   // hole centres the loop below drills

difference() {
  cube(plate, center = true);
  for (centre = feature_centers)
    translate([centre[0], centre[1], 0])
      cylinder(d = hole_d, h = plate[2] + 2, center = true);
}
```

Числа промпта (70, 60, 6, 4, 10.5, 8, и даже 0.05/0.3 из предложения о
допусках) — все шесть/восемь присутствуют в заголовке; `27` и `22` в коде
не написаны, это вычисленные `plate[0] / 2 - edge`. Отверстия сверлятся
**ровно тем массивом**, который объявлен в заголовке, — между «числом в
тексте» и «координатой в коде» нет человека, который бы их сводил.

**Где ещё видно закон.**

- болтовая окружность: `hole_step = 360 / holes`, центры —
  `[pcd_r * cos(start_deg + k * hole_step), pcd_r * sin(start_deg + k * hole_step)]`;
- перфорация: `cols = floor((panel[0] - 2 * margin) / pitch_x) + 1`,
  `origin_x = -span_x / 2`, центры — `[origin_x + i * pitch_x, origin_y + j * pitch_y]`;
- карманы/гнёзда: тот же приём, `feature_centers` — массив, тело читает его.

**Массив центров.** По заявке допускался и закомментированный вариант; здесь
`feature_centers` — настоящая переменная заголовка, потому что так проверка
становится тривиальной и прозрачной: и ваш аудитор, и наш `verify_place1.py`
сравнивают объявленные центры с геометрией буквально.

## E. Что нашлось и что исправлено по ходу

Здесь настоящие ошибки, а не косметика; это стоит перепроверить первым делом.

1. **`perfpanels`: `floor()` в OpenSCAD и `//` в Python расходятся.**
   Делимое `(panel[1] - 2 * margin)` равно 59.400000000000006, делитель 19.8:
   OpenSCAD считает `floor(59.4/19.8) = 3` (то есть 4 ряда), Python — `59.4 // 19.8 = 2`
   (3 ряда). Манифест обещал одни центры, геометрия сверлила другие, и гейт
   ловил «expected a void, found 100 % material». Теперь счётчики считаются
   `math.floor(a / b)` — побитово то же, что делает OpenSCAD, — и в коде стоит
   комментарий, почему нельзя `//`.
2. **`ventrows`, два ряда.** Массив `row2_centers` объявлялся с настоящим Y, а
   тело вычитало `row_offset / 2` второй раз: центры уезжали мимо отверстий.
   Теперь массивы несут реальный Y, тело читает их как есть.
3. **`rackbars`, зубья.** Планка строилась от `y = 0`, а зубья выходили в
   отрицательный Y: габарит по Y был вдвое больше объявленного, а проба «торец
   планки целый» находила 0 % материала. Планка сдвинута на `[-bar_l/2, -bar_w, 0]`,
   а центры зубьев объявляются в полосе зубьев (`-bar_w / 2`).
4. **`cornerplates`, стенка до кромки.** При `hole_d = 10.5` и отступе 3.2…4.8 мм
   отверстие срезало угол насквозь, и деталь распадалась на 5 компонент. Отступ
   теперь зажат снизу `hole_d / 2 + 1.5` (и сверху `min(l, w)/2 - 12`), а ярлык
   дюймовой дроби пересчитывается от итогового значения.
5. **Пробные кубики.** Кубик 0.6·d имеет полудиагональ 0.52·d и вылезал за
   стенку круглого отверстия — «expected a void, found 50 % material». Политика:
   ребро ≤ 0.5·d, а для отверстий ещё и ≤ 0.5·толщины и ≤ 3 мм; проба обязана
   лежать внутри измеренного габарита (иначе она ничего не доказывает).
6. **Посадки площадок.** Площадки/бобышки выходили за габарит (измерено 116 мм
   при объявленных 110): сторона плиты берётся `max(plate, 2·(boss_d + 6))`,
   центр зажимается с запасом `boss_d/2 + 3` от кромки.
7. **`socketpads`.** Отверстие под крепёж было размером с гнездо (23 мм при
   гнезде 30), стенки не оставалось; глубина гнезда и высота площадки
   перепроверены пробами «пол» и «стенка» в кольцевом зазоре. Сквозные резы
   идут от `-height` с высотой `2·height + 2` (раньше сквозное отверстие
   останавливалось ниже верха бобышки и «сквозным» не было).
8. **Карманы.** Вырез-куб ставился углом в объявленный центр (пробы давали 75 %
   материала и 50 % «перемычки»): куб центрируется на `centre - pocket/2`.
9. **Болтовая окружность.** Кольцо обода могло быть тоньше отверстия: `pcd`
   зажат так, чтобы оставалась стенка `hole_d + 3` мм, а проба «перемычка
   между отверстиями и ободом» ставится только если эта стенка реально есть.
10. **Рёбра.** Пробы ставились на середине толщины плиты вместо середины ребра
    (`base_t + rib_h / 2`) и «валились» на пустом месте; шахматные ряды рёбер —
    не зеркала, для них `symmetry: "none"`.
11. **Отчёт генерации.** Общий `write_report` из `gen2` пишет про скобки, шестерни
    и графы; для `place1` текст про графы, вероятность допусков, имена
    `verify_corpus.py` и пункты чек-листа заменены на факты этого корпуса
    (`build_place1._tailor_report`), каждая замена проверяется `assert`, чтобы
    правка в общем модуле не превратилась в тихо неверный аудит-лист.

## G. Честные ограничения

- Локальная проверка — симуляция приёмника на `manifold3d` + `trimesh` и
  собственном вычислителе выражений OpenSCAD; окончательное слово за вашим
  `openscad --backend=manifold`.
- Промпты — композиция из больших пулов (зачин × габарит × признаки × концовка
  × допуски), а не тексты языковой модели; все числа при этом берутся из
  параметров детали, а не выдумываются.
- Допуски `seat_tol` / `free_tol` — цеховые пометки: они объявлены переменными,
  но в геометрии не участвуют (как и в `gen2`), это учебная формулировка.
- Габарит в манифесте — измеренный по телу, а не задуманный.
- Корпус обучает согласованности «число в тексте ↔ число в коде»; он не
  утверждает, что такую деталь можно изготовить без доработки — допуски,
  припуски и зазоры в текстах именно про это.
