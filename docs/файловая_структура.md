## 2. Где веса (самая соль)

Обучаем **не Qwen целиком**, а маленький адаптер поверх. Вес всего обученного — **~20 MB на слой**:

| Что это | Где | Размер |
|---|---|---|
| **Canvas wire** | `checkpoints/wire/canvas.pt` | **5.7 MB** ← это главное — пространственный холст |
| LoRA-адаптер wire | `checkpoints/wire/lora/lora_wire/adapter_model.safetensors` | 5.6 MB |
| Проекторы (in/out) | `checkpoints/wire/{in,out}_projector.pt` | 4+4 MB |
| MLP масштаба | `checkpoints/wire/scale_mlp.pt` | 36 KB |
| **Canvas voxel** | `checkpoints/voxel/canvas.pt` | 270 MB (избыточно) |

Бэкбон Qwen3.5-2B (4.2 GB) — тяжёлый, но **замороженный**. Он не обучается, только висит.

## 3. Производственное видение

### Как сжать

| Шаг | Эффект | Размер после | Инференс |
|---|---|---|---|
| Сейчас (bf16) | — | 4.5 GB | ~11 с на 300 токенов |
| **int4 бэкбон** (AWQ) | -70% | **~1.2 GB** | **~3 с** |
| **Склеить canvas+LoRA в 1 .safetensors** | загрузка мс | **~20 MB** | ~0 |
| **VoxelCanvas prune** | 270 MB → 5 MB | ? | ~0 |

### Как пристыковать к старшей Qwen

Canvas-хук — это просто линейный слой на layer 12 (Mamba-слой). Если взять Qwen3-7B или 14B:
1. Посчитать `depth_ratio * N_layers` = номер слоя для хука
2. Проекторы (linear 512→131072) не меняются — порт тривиален
3. Canvas веса (5–20 MB) переносятся **без переобучения**
4. Надо перебить только LoRA-адаптер (5.6 MB)

### Продакшен-пайплайн (асимптота)

```
пользователь: "ферма Пратта 300×40×80 мм"
→ минер: bbox [300, 40, 80], class=truss
→ [SPECS] -> промпт
→ int4-Qwen + canvas wire (10 MB в 1 файле)
→ код OpenSCAD (~200 токенов ~3 с)
→ OpenSCAD manifold -> STL -> скачивание
```

Итог: **весь проект — 20 MB обученного софта**, бэкбон можно любой Qwen-совместимый.
