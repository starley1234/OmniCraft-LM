# Заявка №4: корпус консистентности размещения (для внешнего агента)

> Триггер этой заявки — зафиксированные ошибки нашей обученной модели:
> «пластина 80×50×6 с 4 отверстиями по углам» — модель поставила отверстия на
> оси, а не в углы; «фланец с 4 М5 по углам» — отверстия на оси, центральное
> отверстие не насквозь. То есть: задаётся номенклатура и габариты, но не
> **местоположение признаков**. Лечение — данные, где соответствие «число в
> промпте ↔ число в коде» проверено машинно, не глазами.

## Закон этой поставки

**Каждое размерное число в промпте обязано явно присутствовать в коде** (как
значение переменной или координата), и наоборот — координаты признаков в коде
выводятся из исчислимых переменных шапки, а не «магическими» литералами.
Пример правильного поведения:

```openscad
$fn = 32;
// Пластина 80x50x6; отверстия по углам, отступ 8 мм от кромки.
plate = [80, 50, 6];
hole_d = 6.0;
edge = 8.0;                       // отступ от кромки (из промпта)
corner_x = plate[0]/2 - edge;     // 32
corner_y = plate[1]/2 - edge;     // 17
...
for (sx = [-1, 1], sy = [-1, 1])
  translate([sx*corner_x, sy*corner_y, -1]) cylinder(d=hole_d, h=plate[2]+2);
```
(промпт при этом говорит «4 отверстия ø6 по углам с отступом 8 мм от кромки»).

## Самопроверка, которую вы обязаны прогнать

Напишите аудитор `check_consistency.py`:
1. из промпта-EN извлекает все числа (int/float, мм);
2. из кода извлекает значения переменных шапки и числовые литералы в
   `translate/cylinder/cube` вызовах;
3. ≥ 90% промптовых чисел должны находиться в коде с допуском 0.5%;
4. геометрический инвариант: для заявленного ряда «N отверстий по углам с
   отступом E» посчитайте из кода фактические центры и проверьте равенство
   числа отверстий и симметрию относительно осей (допуск 1%).

**Детали, помогающие аудитору:** держите координаты центров признаков в
массиве переменной `feature_centers` (можно закомментированной), это сделает
проверку тривиальной и прозрачной для нас.

## Объём и семейства (`optional_data/data/place1/`)

**1 800–2 400 образцов**, семейства с упором на раскладку:
- пластины: 4/6/8 отверстий по углам с переменным отступом; углы «по трём/четырём»;
- фланцы с болтовыми окружностями: N отверстий на радиусе R, стартовый угол;
* панели с перфорацией: прямая сетка (rows×cols, pitch) и шахматная;
- рамки с ребрами через шаг; рёбра в шахматном порядке;
- линейные ряды отверстий с концевыми отступами;
- плиты с карманами по сетке 2×2/3×3 разной глубины;
- планки с отверстиями «через одну», зубчатые рейки с шагом;
- стойки с базовой платформой и анкерными точками по углам;
- крепёж с потайками в произвольных узлах сетки.

Остальное — по `DATASET_REQUEST.md` (формат манифеста, `$fn = 32;`,
перекрытия, язык). Отдел реальности: «по углам» с отступом, дюймы, допуски —
в пропорциях заявки №2.

  определяться числами из текста.
